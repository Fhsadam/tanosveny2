Tanösvény Kalauz – Web-programozás 1 beadandó

Ez a projekt egy PHP, HTML, CSS és JavaScript alapú webalkalmazás, amely a Tanösvény adatbázisra épül.
A célja, hogy egy egyszerű, átlátható és használható webes felületet adjon tanösvények kezeléséhez és bemutatásához.

Mit tud az alkalmazás?

Az oldal a kötelező 7a/2 front-controller megoldás alapján készült. Az index.php az oldal GET paraméter alapján tölti be a megfelelő oldalt, a function_exists és call_user_func használatával.
